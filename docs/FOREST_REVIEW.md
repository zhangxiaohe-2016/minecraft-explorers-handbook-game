# v0.4 森林与指南针审核

## 发现与修正

v0.3 仅添加 compass 库存和领取提示，没有显示、指针或使用入口；旧回归测试未覆盖该新增功能。新增像素灰边、黑色表盘、红针的动态指南针，持有后自动显示，C 打开说明。旧存档已领取的物品直接生效。

瞭望台是教学自建地标，不是书中的林地府邸。旧实现固定摆放高度、没有向南小路，台内几块悬空踏板也没有目的地。现已整理地面、移动箱子到路旁、移除无效踏板，接通村庄—瞭望台—森林和森林—营地两条路。
