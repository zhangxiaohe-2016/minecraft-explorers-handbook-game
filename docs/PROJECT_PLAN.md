# 方境 · 探索者手记

## 产品范围
以用户提供的 Minecraft Explorer’s Handbook 全书为场景与玩法参考，制作中文、第一人称、桌面 3D 单人探索游戏。当前 v0.3 已交付第一章营地，以及第二章的平原村庄往返和森林瞭望台地标；全书仍按下表逐章扩展。面向从未玩过游戏的人：安全教学、渐进提示、暂停、自动存档与明确反馈。

## 技术决策
- Godot 4.7.2 stable，GDScript 类型化业务脚本。正式图形目标 Forward+；M1 Pro 上以运行检查决定画质开关。
- Blender 5.2.1 LTS 制作工具 GLB；像素轮廓挤出有厚度的网格。方块道具用确定性程序纹理和面材质，统一 1 米方块尺度。
- 手工设计场景 + 确定性分区地形。地形每个区块合并可见面；花草使用 MultiMesh，树木复用网格并保持独立采集；地图扩大后再细分区域批次。禁止给每个地形方块添加一个独立 Node。
- 玩法数据放在 JSON，模型、存档与章节依靠稳定 ID 引用。后续真有性能瓶颈再引入 GDExtension，不预先增加 C++ 或 .NET 环境。
- 数据、存档、世界、玩家、UI 分离。存档版本化；章节状态可扩充。
- 不把联网账号、多人与无限世界纳入第一阶段。

## 教学改编，明确与书区分
- 书中需主动建造庇护所；本关提供逐块蓝图与营地标记，屋顶/墙使用圆石、门使用木门。采集石头仍需木镐。
- 教学日照不倒计时；玩家完成准备后主动开始首夜，避免初学者因阅读说明被惩罚。
- 首夜是短时安全庇护挑战，不在首版实现完整怪物 AI、饥饿、装备耐久和死亡掉落。
- 本关固定采集点单次产出多份材料，减少重复劳动；不表示原版每个方块的掉落数。
- 熔炉仅可制作/摆放，不显示未实现的冶炼按钮；后续正式实现燃料与输入输出规则。
- 完成首夜只解锁下一章的规划卡，不代表第二章已可游玩。

## 实施顺序
1. 环境安装、书图参考索引、全书规划、JSON 物品和配方。
2. 工具模型与像素材质；可行走的林地、水域、石丘和营地。
3. 采集 → 木板/木棍 → 工作台 → 木镐 → 圆石/煤 → 小屋/门/火把。
4. 渐进任务提示、教程、背包制作、章节手记、保存与加载。
5. 图形实机检查、输入与完整流程验证、文档与启动器。

## 质量门槛
目标 M1 Pro 原生桌面 1280×800 下流畅交互。以实测报告性能，不承诺未测帧率。每件关键道具检查书图对照、游戏内可识别性、碰撞与交互。存档不能靠关闭进程前的单次写入，关键动作后保存。全流程测试必须经过真实配方约束，不能只把任务标志改成完成。
