# v0.5.2 · 工具耐久与备用工具

依据《Minecraft Explorer’s Handbook》印刷第 9、16–17 页，为木镐、石斧、木剑加入独立耐久、磨损提示与备用切换。

## 规则（书中数值）

| 工具 | 满耐久 | 有效磨损 |
|---|---|---|
| 木镐 | 59 | 成功开采圆石/煤矿 |
| 木剑 | 60 | 府邸成功命中 |
| 石斧 | 132 | 成功砍原木，或府邸成功命中 |

火把与空手不计入耐久。挥空、暂停菜单、失败交互不扣耐久。数值取自书中第 16–17 页材料耐久表，不是另行编造的教学魔改。

## 玩法

- 快捷栏下方显示当前工具「耐久 x / y · 共 n 把」；约 20% / 10% 时提醒准备备用。
- 仅当前手持的那一把会磨损；同类多把各自独立记录。
- 损坏只消耗一件：有备用则自动换上；没有则回空手，并提示按 Tab 再制作。
- 新制作的工具为满耐久。

## 存档

- 写入 version 3 字段 `tool_durability`。
- 旧档（v1/v2）数量全部保留，首次迁移时初始化满耐久，并生成 `.pre-v3` 备份。
- 反复读档不会复制工具，也不会把已磨损耐久刷回满值。

## 验证

`tests/test_durability.gd`：规则、独立实例、低/关键耐久、损坏与备用、真实左键采矿、暂停不耗、制作满耐久、读档与旧档迁移。headless 与原生 Metal 均 0 failures。规则/首夜/村庄/森林/府邸/书页专项回归通过。
