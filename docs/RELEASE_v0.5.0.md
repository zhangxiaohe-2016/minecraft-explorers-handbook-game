# v0.5.0 · 林地府邸

按《Minecraft Explorer’s Handbook》印刷页 30–31 的图片和文字，新增森林考察之后的府邸探索路线。

- 三层深木与圆石建筑、窗格、红毯走廊与可步行木梯。
- 农场房、巨鸡雕像线索、储藏房、牢房、书架后的秘密房间与仿制传送门。
- 巡逻卫道士、唤魔者地面尖牙；攻击前有预警，可用石斧击退或躲避。
- 生命与食物恢复、床边安全撤退；生命耗尽保留物资。
- 给悦灵一块原木后跟随，带回考察手记与发现完成路线。
- 兼容现有存档，已打开的门、房间奖励、击退记录和悦灵跟随状态在重启后恢复。

森林考察完成后，带石斧、面包或熟牛肉与原木，到营地南侧府邸正门旁按 E 阅读须知。3 装备石斧，按住左键攻击，F 吃食物，Esc 暂停。

规则、第一章、村庄、森林回归以及府邸原生 Metal 完整流程和场景重载测试通过。此版本是简化教学：固定布局和距离、简化战斗数值；恼鬼召唤、装备耐久、护甲及悦灵自动收集物品尚未实现。具体书页依据见 docs/MANSION_PLAN.md。

Release 提供源码，不包含独立安装包。使用 Godot 4.7.2 导入 project.godot 运行。非官方项目。
