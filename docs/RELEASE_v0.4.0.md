# v0.4.0 · 指南针与森林考察

修复 v0.3 指南针只有库存、没有显示和方向的问题。领取后自动显示灰边黑盘红针，随玩家转身实时指向世界出生点；C 打开使用说明，睡床不改变普通指南针指向。已经领取指南针的存档直接生效。

按书第 28–29 页新增繁花森林、白桦林、黑森林的观察路线，包含成簇花朵、白色斑纹树干、深色树冠和红白巨型蘑菇。E 查看观察牌并记录三种森林，随后借助指南针返回出生点。连接村庄、瞭望台、森林与营地的小路，并修正旧瞭望台地面和箱子高度。

第 18 页是指南针规则与外观依据。瞭望台和观察任务为教学设计；尚未加入磁石、染料、狼、敌对生物或林地府邸。下一节依书序为第 30–31 页林地府邸。

规则、第一章、村庄回归均通过；新增森林与指南针原生图形专项测试通过。测试使用独立存档，兼容玩家现有进度。

本 Release 提供源码，不附独立安装包。使用 Godot 4.7.2 导入 project.godot 运行。非官方项目。
