# v0.5.3 · 石镐采铁到第一把铁镐

依据《Minecraft Explorer’s Handbook》印刷第 9–10、17 页，补全从圆石到铁镐的资源链；不使用赠送箱代替矿物来源。

## 玩家路线

1. 用木镐采圆石 → 工作台 **3 圆石 + 2 木棍 = 石镐**（耐久 131）。
2. 到营地南侧「铁矿脉」：**只有石镐或铁镐**能开采；木镐无产量。
3. 每块铁矿得 **1 粗铁** → 熔炉 **粗铁 → 铁锭**（消耗燃料，6 秒教学时间）。
4. 工作台 **3 铁锭 + 2 木棍 = 铁镐**（耐久 250，书中第 17 页）。

## 系统接入

- 快捷栏第 2 槽自动装备**当前最好的镐**（铁 > 石 > 木）；损坏后自动降级到下一档。
- 新镐进入独立耐久；采矿成功才磨损。
- 熔炉面板新增「粗铁 → 铁锭」；忙碌时拒绝第二份。
- 材料不足、缺工作台、工具等级不够均有明确提示。

## 同轮补强（耐久证据）

- 真实左键命中卫道士才扣剑耐久；无目标挥空不扣；冷却挡住连击。
- `.pre-v3` 备份断言为原始 v2 内容与数量，不会被 v3 重写覆盖。

## 验证

`tests/test_iron.gd` 与强化后的 `tests/test_durability.gd`：headless 与原生 Metal 均 0 failures。规则/首夜/村庄/森林/府邸/书页/质量回归通过。截图 `artifacts/iron-chain.png`。

范围外：完整地下洞穴、金/钻石、护甲、附魔。铁矿为地表教学矿脉（书中写 underground，本关改可达地表并标明）。
