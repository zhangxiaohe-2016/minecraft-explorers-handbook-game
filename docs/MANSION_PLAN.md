## 可玩的路线

森林考察完成 → 准备石斧与食物 → 正门阅读说明 → 一楼农场与雕像 → 二楼储藏和牢房 → 三楼秘密房间 → 带着发现返回营地。

正门位于营地南侧小路尽头。每层走廊末端通向木梯；楼梯坡度约 27°，无需跳跃。左右房间分别在建筑西、东侧。墙体参与攻击视线判断；守卫不会隔墙直接造成伤害。可击退或绕过守卫。

## 教学改编与范围

- 书中府邸常在远处；本版压缩距离，把固定府邸放在黑森林邻近区域，仍使用现有 96×96 米地图。房间布局手工设计，并非原版随机府邸的逐块复制。
- 地上窗户目前为装饰窗格，不是可破坏玻璃。观景窗、自由破坏建筑不在本版范围内。
- 卫道士抬斧 0.9 秒、唤魔者地面预警 1.2 秒；石斧命中三次击退。不是原版伤害、攻速或生命参数。
- 生命 10 点，食物即时恢复 2 点生命，睡床恢复满生命。生命耗尽回到床边、保留物品，战斗无掉落惩罚。
- 每个房间共享一次性补给标记，不能利用多个箱子重复领取。击退记录持久化；尚未击退的守卫在重开游戏后恢复初始生命。
- 雕像线索、推开书架、考察手记和任务顺序是教学设计。仿制传送门不能传送，没有加入书图中的 TNT 爆炸。
- 悦灵为依据文字重建的蓝色方块模型，收到原木后作为跟随伙伴。暂不支持自动收集散落物、寻路绕墙、物品归还或完整原版悦灵 AI。
- 唤魔者尚不能召唤恼鬼。没有加入护甲、盾牌、装备耐久或完整怪物种群。
