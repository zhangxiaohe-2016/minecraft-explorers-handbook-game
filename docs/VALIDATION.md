# 第一章验证记录

环境：2026-09-14，Apple M1 Pro（14 核 GPU / 16GB），Godot 4.7.2 stable，Blender 5.2.1 LTS。图形运行日志确认 Metal 4.0 / Forward+。

## 已验证

- 编辑器导入：字体、12 张程序像素纹理、3 个 GLB 模型；模型源文件与书图参考不进入 Godot 导入流程。
- 场景启动：46 块蓝图、123 个可采集资源点；玩家出生后站在碰撞地形上。
- 规则测试：从空背包开始，真实消耗配方材料；无木镐不能采石、无材料不能制作、工作台距离限制、重复采集与建造不重复发放或扣费。
- 数据存档：背包、耗尽资源、建造、任务、玩家位置保存后恢复；测试使用独立的临时文件。
- 实机集成：W 输入移动角色，摄像机射线命中树干，按住左键采集成功；实际实例化 Blender GLB 到第一人称手上。
- 世界交互：放置工作台、46 块圆石建筑、木门、火把与可选熔炉；准备齐全后屋内才能开始夜晚。
- 首夜：开门时暂停守候；关门后推进到黎明；显示结局与全书章节手记。
- UI：已检查中文渲染、营地画面与六件道具样板；游戏内菜单热键在 `_input` 处理，避免 Tab 被按钮焦点导航吞掉。
- macOS 启动：本地原生通用二进制启动器使用系统 `open -n -a` 启动指定 Godot 应用；无需终端窗口。

## 图形采样

1280×800 的已建成营地固定视角，在完整集成流程完成、着色器预热后，最新一次采样为 **120 FPS / 841 draw calls / 379,376 primitives**。这是单个视角的即时读数，不是全地图平均值或帧率下限。后续章节、水下效果和大量生物需要独立基准。

复用同尺寸网格与纹理材质后，该视角 draw calls 从 2,364 降至 841。地形仍以 16×16 列分区、可见面合并；花草为实例化批次。树木使用共享网格实例，以保留独立采集能力。
